DataCo Supply Chain Dataset

## Dataset Overview

This project uses the DataCo Smart Supply Chain Dataset, which contains e-commerce order, customer, product, and shipping information.
The dataset is used to analyze delivery performance, identify shipping bottlenecks, evaluate late deliveries, and measure their business and customer impact.

| Attribute | Details |
|---|---|
| Dataset Name | DataCo Smart Supply Chain Dataset |
| Source | Kaggle |
| Domain | E-commerce & Supply Chain |
| Time Period | 2015–2018 |
| Records | Approximately 181K orders |
| Format | CSV |
| Analysis Tools | Python, Pandas, NumPy, Power BI |

## Dataset Source
